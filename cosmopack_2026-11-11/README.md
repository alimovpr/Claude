# Cosmopack — 11.11.2026

Контакты с выставки, заполняются по фото визиток и стендов (как на Cosmetic 360 в Париже — см. `../exhibition`).

- `photos/` — фото визиток/стендов (`001_компания.jpg`, `001b_...` — доп. фото)
- `contacts.json` — данные (одна запись = одна компания)
- `build.py` — собирает `contacts.xlsx` (листы «Контакты» и «По странам»)
